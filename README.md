🎧 AI Video Transcriber

An AI-powered hybrid web application that converts YouTube videos into accurate text transcripts and allows users to download the transcript as a multi-page PDF.

This project integrates Artificial Intelligence + Web Development + NLP, making it suitable for mini projects, final-year projects, and portfolios.

🚀 Features

🔗 Accepts YouTube video links

🎧 Automatically extracts audio from videos

🧠 Converts speech to text using OpenAI Whisper

📝 Formats transcription into readable paragraphs

📄 Downloads full transcription as a multi-page PDF

🎨 Modern purple glitter-style UI

🌐 Web-based interface using Flask

🧠 Technology Stack
Category	Tools
Programming Language	Python
Backend	Flask
AI Model	OpenAI Whisper
Video Processing	yt-dlp
Audio Processing	FFmpeg
PDF Generation	ReportLab
Frontend	HTML, CSS, JavaScript
